# 求职台·试用

已审阅界面的软件内试用版。侧栏打开「求职台·试用」，「今天」也有独立求职卡片。

- 单击岗位查看详情，右键选择编辑；详情右上角「⋯」提供同一菜单。
- 可修改资料、阶段、笔试/面试轮次与时间；右侧面板全高，底部保存按钮固定。
- 今天卡片和求职表格共用本次试用记录。
- 「预览任务卡片」只展示样例，不创建软件中的任务。

**所有内容均为演示数据。编辑只在本次插件运行中保留；重载、停用或重启后恢复样本。请勿把它作为真实求职记录的保存工具。**

权限只有 View 和 TodayCard；不读取或写入真实任务、笔记或插件 KV，不访问网络。

在软件「插件 → 导入插件」选择提供的 ZIP，导入后审阅并启用即可。正式版会采用独立 ID `com.leeyl.job-tracker`，此试用版 ID 为 `com.leeyl.job-tracker-trial`。

需要支持 `plugin.protocol/v2`、带「导入插件」入口的桌面程序。旧安装版没有该入口时，请打开项目构建的新版桌面程序。

开发：在本插件目录运行 `npm run build && npm test`；构建依赖仓库现有 React/Lucide。生成的 `main.js` 没有外部运行依赖。
