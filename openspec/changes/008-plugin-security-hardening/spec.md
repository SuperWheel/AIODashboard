# Spec 008: 插件安全与生命周期加固

## ADDED

### ADDED-1：插件上下文

- **要求**：所有插件来源的 Core、KV、HTTP、源代码读取和生命周期操作必须使用宿主建立的上下文 token；不得信任前端传入的 plugin id 或 actor。
- **要求**：上下文绑定插件 id、启用状态、registry revision 和全部运行文件内容指纹；停用、重载或 manifest 变化后旧 token 失效。

### ADDED-2：显式能力

- **要求**：未声明 Core/UI/事件/网络/cron 能力的调用拒绝；旧 manifest 不再拥有宽权限兼容。
- **要求**：拒绝调用产生结构化错误、`plugin.denied` 事件和 activity log。
- **要求**：领域事件只允许订阅；自定义事件必须使用插件自己的命名空间。

### ADDED-3：数据与网络边界

- **要求**：KV 按 manifest quota 强制执行，按 UTF-8 字节数计算；跨插件读取和写入拒绝。
- **要求**：网络代理使用标准 URL 解析，逐个检查 DNS 解析地址，限制 GET、超时和响应大小，并审计成功与失败请求。

### ADDED-4：安全安装与回滚

- **要求**：ZIP 拒绝路径穿越、symlink、hardlink、过大文件、过多文件和目录外入口；manifest.id 必须等于包根目录名。
- **要求**：安装失败恢复旧版本；回滚按精确插件 id 选择并重新校验；新安装默认停用。
- **要求**：运行时加载校验已记录完整性哈希，来源、版本和回滚元数据保持一致。

### ADDED-5：生命周期与开发体验

- **要求**：onload 失败、超时或取消时清理所有注册项；注册 API 返回 disposer；设置使用声明式定义并持久化。
- **要求**：CLI 变更可被运行中的 GUI 发现并自动 reload。
- **要求**：SDK、测试桩、脚手架、插件手册和 CI 覆盖上述契约。

## MODIFIED

- 插件 API 为 `plugin.protocol/v2`；旧版本仅可诊断，不可运行。缺省/null quota 均无存储权限。
- AI CLI schema_version=6，permission_denied 对应 exit 4；新增授权、完整性和修订读模型。
- 数据库新增 V8，迁移停用既有插件并要求重新授权，不改历史迁移。
- GUI 安装、回滚入口采用计划允许的 CLI-only 方案；页面和手册明确命令，GUI 保留权限审阅、设置、启停与重载。

> 2026-09-08 后续演进：[桌面统一导入 Plan](../../../docs/plans/2026-09-08-plugin-import-entry.md) 增加 ZIP / 文件夹导入入口，沿用预检确认、默认停用及重新授权。上述 CLI-only 是 008 原交付记录；当前回滚继续采用 CLI。

## 非本变更范围

- 不实现 Worker/WASM/独立进程隔离。
- 不实现公共插件市场、在线账号体系或跨设备同步。
