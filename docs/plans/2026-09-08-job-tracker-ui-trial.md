## 需求

用户审阅界面后要求导入软件试用，并明确选择「先导入界面试用版（使用演示数据）」。将已审阅的表格、右键菜单和全高编辑器做成独立插件，注册真实侧栏 View 和 TodayCard；移除演示应用外壳，沿用实际软件的导航与主题。

- ID：`com.leeyl.job-tracker-trial`，名称「求职台·试用」，稳定版本 `0.1.0`。不占用正式插件 ID。
- 只声明 `ui.view`、`ui.today_card`，不申请 Core、KV、网络、事件或 cron 权限。
- 虚构记录仅在插件实例的内存中；在侧栏/今天间切换时共用，重载/停用/重启恢复样本。明确标记，不能录入后误认为已经保存真实数据。
- 「预览任务卡片」只显示内存示例，不创建软件任务，也不变更已有任务统计。正式来源关联仍保留在 Spec 009。
- 托管侧栏契约尚未实施；这个可信本地试用插件使用自身严格限定的 fixed 覆盖层与监听器，卸载清理，不推广为正式通用 UI API。
