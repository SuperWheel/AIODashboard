# Plan：任务卡片墙双视图——均衡发牌混排 + 类型分区

> 级别：Plan · 状态：已完成（2026-08-31）
> 提出日期：2026-08-31
> 关联：dev-log 2026-08-31 走查反馈

## 需求

- 现状：任务页卡片墙为简单两列网格（`align-items: stretch`），同行卡片被行内最高卡（年卡约 560px）拉伸，日卡出现大片空白。
- 预期（用户指定方案）：① 默认「均衡混排」——按顺序把卡片发进**当前最矮的列**，年卡先落一列后，月卡/周卡等短卡连续补到另一列直至两边高度接近，卡片互不拉伸；② 新增「类型分区」视图——按日/周/月/年分区展示。两种模式可在页头切换，选择记忆在 localStorage。

## 分步计划（均已完成）

- [x] 1. hooks 增加 `useMinWidth(px)`（与 Tailwind xl=1280 断点同步，驱动 JS 侧列数）。
- [x] 2. TasksView：各样式高度档位估算表 + `dealColumns` 贪心发牌（前缀稳定，新增任务不搬动已有卡片）；混排为两列 flex 列、`items-start` 不拉伸。
- [x] 3. 「类型分区」视图：日/周/月/年四区，区间两列网格、空区隐藏。
- [x] 4. 页头右侧模式切换（圆角矩形按钮组，与 tab 同款式），localStorage 记忆（`aiodashboard.tasks.wallMode`）。

## 验证

- [x] tsc + vitest 22 全过；dev 热更真机确认
- [x] 混排：年卡不再拉伸同行日卡；新增任务不引起已有卡片换列
- [x] 分区：四区按样式归组，模式切换即时生效且记忆

## 结果记录

2026-08-31 完成，同日多轮走查迭代：
- **墙序与状态解耦**：混排/分区均按 `created_at` 升序（新任务固定最末，落在当前较矮列底部）；打卡完成不再改变卡片位置。
- **发牌高度来源改为实测**：估算档位（副标题换行、月卡行数等动态因素）始终不准，最终方案为 MeasuredCard（useLayoutEffect 首帧同步上报 offsetHeight + ResizeObserver 跟踪），发牌用实测值、估算仅作首帧兜底；卡片高度与所在列无关，重排收敛无循环。
- 任务编辑器补「删除」（danger 按钮 + 二次确认，级联删账本/区间）。

若后续卡片内容改版，无需再维护档位表——实测自动适应；`CARD_HEIGHT_EST` 仅在首帧兜底时生效。
