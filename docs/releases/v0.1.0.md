# AIODashboard v0.1.0

首个公开发行版本：一个本地优先的 macOS 个人工作台，桌面端与 JSON CLI 共用 Rust Core 和 SQLite。

## 下载

| 附件 | 用途 |
|---|---|
| AIODashboard_0.1.0_aarch64.dmg | Apple Silicon Mac 桌面安装包 |
| dashboard_0.1.0_aarch64-apple-darwin.tar.gz | 同架构的独立 CLI，含许可证与使用说明 |
| SHA256SUMS.txt | 两个二进制附件的 SHA-256 校验和 |

下载地址：[GitHub Release](https://github.com/SuperWheel/AIODashboard/releases/tag/v0.1.0)。源码归档由 GitHub 提供。

打开 DMG，将 AIODashboard 拖入「应用程序」。CLI 解压后运行 `./dashboard --help`；如需任意目录调用，可自行放入 PATH 中的用户目录。

本次仅构建并验证 macOS Apple Silicon；尚无 Intel、Windows 或 Linux 预编译包。程序使用本地 ad-hoc 签名，没有 Apple Developer ID 分发签名或公证。macOS 可能提示无法验证开发者；先核对下载来源和校验和，再按「系统设置 → 隐私与安全性」提示处理，无需关闭系统整体安全保护。

## 主要功能

- 今日概览：任务进度、近一年热力、重要日、最近笔记与活跃项目。
- 任务打卡：目标、循环规则、撤销、周月年总览、星级与拖拽排序；首页卡片统一为低饱和主题绿。
- 倒计时与纪念日、项目、笔记、收件箱和全局搜索。
- 插件 ZIP / 文件夹导入、预检、替换确认、权限审阅、默认停用、设置与重载；CLI 安装与回滚。
- JSON CLI、今日上下文、幂等打卡、操作来源与活动日志。

不预装番茄钟。仓库中的番茄钟示例尚未完成，不作为本次已交付功能；求职台试用也是演示数据界面，重载恢复样本。

## 升级与兼容

应用版本 0.1.0；CLI JSON schema 6；插件协议 plugin.protocol/v2；数据库 V8；公共 SDK/test 0.2.0。这些版本各自独立。

升级前退出桌面应用与 CLI，并备份整个 `~/Library/Application Support/AIODashboard/` 目录；若使用自定义数据库或插件路径，也备份对应目录。数据库迁移仅向前执行，不支持直接用旧程序降级读取新版数据库。

V8 会停用旧插件；旧 manifest 需按 [插件开发手册](https://github.com/SuperWheel/AIODashboard/blob/v0.1.0/docs/PLUGIN_API.md) 迁移，再审阅权限启用。新装、替换与回滚也默认停用。

## 已知边界

- Trusted WebView 与宿主同进程，权限检查不是恶意代码沙箱，只运行可信插件。
- 没有内置 AI 聊天、云同步、原生 WidgetKit 小组件或自动更新器。
- 网络插件依其显式权限联网；核心个人数据保存在本机。
- 此为早期版本，请保留数据备份并通过 Issues 提交可复现问题。

## 验证

完整门禁通过：104 项 Rust 测试、45 项 Vitest、7 项 SDK/示例测试，fmt、clippy 和构建通过。首页配色调整后重新通过 frontend 门禁，复用未修改的 Rust 结果。发行构建与真实桌面检查使用隔离演示数据，不包含个人任务或预装插件。
